| Ресурс                                        | Тип                                                         | Для чего подходит       | Как использовать                                                             | Заметки                                                                                |
| --------------------------------------------- | ----------------------------------------------------------- | ----------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| [Dribbble](https://dribbble.com/)             | Соцсеть дизайнеров, портфолио проектов                      | Вдохновение             | Смотреть шоты, подборки и стили, искать референсы по тегам                   | Много концептов и мало реальных сайтов, поэтому для проверки реализуемости не подходит |
| [OriginKit](https://www.originkit.dev/)       | Репозиторий компонентов, секций и шаблонов с исходным кодом | Готовый код для проекта | Через MCP: ИИ-агент сам находит и подтягивает компоненты                     | Код можно брать сразу, но стоит проверить лицензию и совместимость со стеком           |
| [21st.dev](https://21st.dev/)                 | Репозиторий компонентов, секций и шаблонов с исходным кодом | Готовый код для проекта | Через MCP: ИИ-агент сам находит и подтягивает компоненты                     | Ориентирован на React и Tailwind, компоненты публикует сообщество                      |
| [Dprofile](https://dprofile.ru/)              | Соцсеть идей, стиля, проектов и графики                     | Вдохновение             | Искать референсы по стилю, графике и проектам                                | Русскоязычное комьюнити, в основном визуальные работы                                  |
| [Awwwards](https://www.awwwards.com/)         | Подборка лучших сайтов с рейтингом и наградами              | Вдохновение             | Смотреть победителей («Site of the Day») и анимации, брать идеи для эффектов | Много экспериментальных и тяжёлых сайтов, не все решения применимы в продакшене        |
| [Lapa Ninja](https://www.lapa.ninja/)         | Галерея лендингов                                           | Вдохновение             | Подбирать референсы по нише и типу секции                                    | Удобна для сравнения структуры лендингов                                               |
| [Landingfolio](https://www.landingfolio.com/) | Галерея лендингов и секций                                  | Вдохновение             | Подбирать референсы по нише и типу секции                                    | Часть функций может быть платной                                                       |

| Цель                    | Ресурсы                            |
| ----------------------- | ---------------------------------- |
| Идеи и стиль (концепты) | Dribbble, Dprofile                 |
| Примеры реальных сайтов | Awwwards, Lapa Ninja, Landingfolio |
| Готовый код (через MCP) | OriginKit, 21st.dev                |
