# SSE-S3 и SSE-KMS в RustFS

> [!abstract] Цель
> Понять, какой мастер-ключ (KEK) защищает ключи данных (DEK), как менять ключи и можно ли назначать их объектам по префиксу.

**Условие:** в RustFS настроен Vault Transit, а `Default SSE Key` равен `rustfs-default-key`.

## 1. SSE-S3 — ключ выбирает RustFS

- В настройках бакета включаем **SSE-S3**. При обычном `PutObject` RustFS шифрует новые объекты автоматически.
- Для каждого нового объекта используется собственный **DEK**; его защищает **KEK**, выбранный как глобальный `Default SSE Key` в разделе **KMS Configuration**.
- Если включить SSE-S3 на другом бакете того же кластера, он также использует этот ключ по умолчанию. Назначить отдельный KEK для SSE-S3 конкретному бакету через эту настройку нельзя.
- **Ротация KEK поддерживается:** Vault создаёт новую версию ключевого материала под тем же ID; старые версии остаются нужны для расшифровки прежних DEK.

## 2. SSE-KMS — можно выбрать KEK

- В настройках бакета включаем **SSE-KMS** и указываем **KMS Key ID** для новых объектов по умолчанию.
- При отдельном `PutObject` можно явно указать другой Key ID. Поэтому объекты в одном бакете способны использовать **разные KEK**, сохраняя индивидуальные DEK.
- Ротация каждого ключа выполняется отдельно. **Key ID остаётся тем же**, меняется версия секретного материала.

## 3. Можно ли задать ключи по префиксам?

**Штатных правил шифрования по префиксу у бакета нет.** Нельзя настроить в Console правило вида:

```text
finance/* → finance-key
patents/* → patents-key
```

Такой выбор реализует приложение при загрузке объекта, указывая нужный `--ssekms-key-id`:

```bash
aws --endpoint-url http://127.0.0.1:9000 s3api put-object \
  --bucket my-bucket \
  --key finance/report.pdf \
  --body report.pdf \
  --server-side-encryption aws:kms \
  --ssekms-key-id finance-key
```

Для `patents/` приложение аналогично использует `patents-key`.

## 4. Главное различие

| | SSE-S3 | SSE-KMS |
|---|---|---|
| Как выбирается KEK | Глобальный Default SSE Key | Ключ бакета или явный Key ID объекта |
| Несколько KEK в одном бакете | Не через SSE-S3 | Да, при явном выборе на загрузке |
| Ротация Vault Transit | Да | Да |
| Значение S3 API | `AES256` | `aws:kms` |
