## `fzf` — интерактивный поиск

`fzf` позволяет быстро выбирать файлы, команды и другие элементы через нечёткий поиск.

```bash
fzf
```

Найти файл:

```bash
find . -type f | fzf
```

Открыть найденный файл в `micro`:

```bash
micro "$(find . -type f | fzf)"
```

Полезные сочетания:

```text
Ctrl + R — поиск по истории команд
Ctrl + T — поиск файла
Alt + C  — переход в найденную директорию
```

## `ripgrep` (`rg`) — поиск текста в файлах

Найти текст во всех файлах текущей директории:

```bash
rg "FastAPI"
```

Без учёта регистра:

```bash
rg -i "fastapi"
```

Искать только в Python-файлах:

```bash
rg "TODO" -g "*.py"
```

Показать только имена файлов:

```bash
rg -l "TODO"
```

Показать по три строки контекста:

```bash
rg -C 3 "error"
```

Искать в скрытых файлах:

```bash
rg --hidden "text"
```

## `starship` — оформление командной строки

`starship` отображает полезную информацию прямо в терминале:

- текущую директорию;
    
- Git-ветку;
    
- состояние Git-репозитория;
    
- версию Python;
    
- активное виртуальное окружение;
    
- статус предыдущей команды.
    

Открыть конфигурацию:

```bash
micro ~/.config/starship.toml
```

Создать файл конфигурации:

```bash
mkdir -p ~/.config
touch ~/.config/starship.toml
```

После настройки `starship` работает автоматически при открытии терминала.

## `bat` — улучшенный `cat`

Показать содержимое файла с подсветкой синтаксиса:

```bash
bat main.py
```

Показать несколько файлов:

```bash
bat main.py config.py
```

Показать определённый диапазон строк:

```bash
bat --line-range 10:30 main.py
```

Вывести файл без рамок и дополнительного оформления:

```bash
bat --style=plain main.py
```

Найти файл через `fzf` и открыть его:

```bash
bat "$(find . -type f | fzf)"
```

## `eza` — улучшенный `ls`

Показать файлы:

```bash
eza
```

Подробный список:

```bash
eza -l
```

Показать скрытые файлы:

```bash
eza -la
```

Показать размеры файлов в удобном формате:

```bash
eza -lah
```

Показать Git-статус файлов:

```bash
eza -lah --git
```

Показать дерево директорий:

```bash
eza --tree
```

Ограничить глубину дерева:

```bash
eza --tree --level=2
```

Полезные алиасы:

```bash
alias ls='eza'
alias ll='eza -lah --git'
alias tree='eza --tree'
```

## `yazi` — файловый менеджер в терминале

Запустить:

```bash
yazi
```

Навигация:

```text
j / ↓     — вниз
k / ↑     — вверх
h / ←     — назад
l / →     — открыть директорию
Enter     — открыть файл
Space     — выделить файл
q         — выйти
```

Работа с файлами:

```text
y — копировать
x — вырезать
p — вставить
d — удалить
r — переименовать
a — создать файл
A — создать директорию
/ — поиск
~ — справка по горячим клавишам
```

## `micro` — терминальный текстовый редактор

Открыть файл:

```bash
micro main.py
```

Создать новый файл:

```bash
micro notes.md
```

Открыть несколько файлов:

```bash
micro main.py config.py
```

Основные сочетания:

```text
Ctrl + S — сохранить
Ctrl + Q — выйти
Ctrl + C — копировать
Ctrl + X — вырезать
Ctrl + V — вставить
Ctrl + Z — отменить действие
Ctrl + Y — повторить действие
Ctrl + F — поиск
Ctrl + H — найти и заменить
Ctrl + L — перейти к строке
Ctrl + G — открыть справку
```


