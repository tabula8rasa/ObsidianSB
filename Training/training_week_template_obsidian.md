# Шаблон недели тренировок

## Главная идея недели

План:

- **3 дня зала**
- **3 дня бег / велосипед**
- **1 день отдыха**

В зале каждый день:

- 2 упражнения на грудь
- 2 упражнения на спину
- 1 малая группа мышц: трицепс / бицепс / плечи
- предплечья
- икры
- пресс

В дни бега / вело:

- выбирать вид спорта и дистанцию по состоянию
- основной фокус: интервальные тренировки
- при сильной усталости заменять интервалы на лёгкую аэробную работу

> [!important]
> Если по самочувствию тренировка явно не идёт, лучше снизить объём или интенсивность, чем добивать план любой ценой.  
> Главный показатель прогресса — стабильность, а не одна героическая тренировка.

# Система оценки тренировки

После каждой тренировки заполняй блок **"Оценка тренировки"**.

## Баллы

Каждый пункт оценивается от `0` до `2`.

| Балл | Значение |
|---|---|
| `0` | плохо / не выполнено |
| `1` | средне / частично |
| `2` | хорошо / выполнено |

## Итоговая оценка

Максимум: `20 баллов`.

| Баллы | Итог |
|---|---|
| `18–20` | Отлично |
| `14–17` | Хорошо |
| `10–13` | Нормально |
| `6–9` | Плохо |
| `0–5` | Провал / восстановление |

## Метрики

| Метрика | Смысл |
|---|---|
| `energy` | было ли достаточно энергии |
| `focus` | была ли концентрация |
| `target_muscle_feel` | хорошо ли чувствовал целевую мышцу |
| `technique` | сохранялась ли техника |
| `breathing_control` | не сбивалось ли дыхание |
| `plan_completed` | выполнил ли весь план |
| `progression` | удалось ли сохранить/увеличить вес, темп, объём |
| `recovery_feeling` | не было ли ощущения перегруза |
| `pain_free` | не было ли боли в суставах/связках |
| `mood_after` | стало ли лучше после тренировки |
