# Поиск дубликата в массиве через алгоритм Флойда (tortoise & hare)

## 1. Условие задачи

Дан массив длины $n+1$, содержащий числа из диапазона $[1, n]$. Известно, что **ровно одно** число повторяется дважды, все остальные встречаются ровно один раз. Требуется найти это повторяющееся число.

**Ограничения классической формулировки (LeetCode 287 — Find the Duplicate Number):**
- нельзя изменять массив,
- нужно использовать $O(1)$ дополнительной памяти,
- временная сложность — $O(n)$.

Именно эти ограничения делают неприменимыми простые решения (сортировка, hash-set) и подводят к трюку с построением неявного связанного списка.

## 2. Идея решения и код

**Идея:** трактуем массив как функцию $f(i) = a[i]$, задающую граф, где каждый индекс — узел, а `a[i]` — указатель на следующий узел. Такой граф гарантированно содержит цикл (см. пункт 3), а точка входа в цикл — это и есть искомый дубликат (см. пункт 4).

Алгоритм в два прохода:
1. **Находим точку встречи** внутри цикла — черепаха (шаг 1) и заяц (шаг 2), стартуют из индекса `0`.
2. **Находим точку входа в цикл** — один указатель возвращаем в начало, второй оставляем в точке встречи, оба теперь движутся с одинаковой скоростью (по 1 шагу); узел, где они встретятся — дубликат.

```python
def find_duplicate(nums: list[int]) -> int:
    # Фаза 1: поиск точки встречи внутри цикла
    tortoise = nums[0]
    hare = nums[0]
    while True:
        tortoise = nums[tortoise]
        hare = nums[nums[hare]]
        if tortoise == hare:
            break

    # Фаза 2: поиск точки входа в цикл (дубликата)
    tortoise = nums[0]
    while tortoise != hare:
        tortoise = nums[tortoise]
        hare = nums[hare]

    return tortoise
```

Сложность: $O(n)$ по времени, $O(1)$ по памяти.

## 3. Почему построение гарантированно даёт цикл + хвост

Рассматриваем граф на индексах $\{0, 1, \dots, n\}$, где каждый узел $i$ имеет ровно одно исходящее ребро в $a[i]$.

**Почему цикл вообще возникнет:**
Значения $a[i] \in \{1,\dots,n\}$ — то есть узлы $\{1,\dots,n\}$ образуют самоотображение конечного множества в себя: $f: \{1,\dots,n\}\to\{1,\dots,n\}$. Пройдя по стрелкам $n+1$ шаг из любой точки, мы посетим $n+1$ значений из множества размера $n$ — по принципу Дирихле хотя бы два значения совпадут: $x_i = x_j$. Поскольку $f$ детерминирована, из этого следует $x_{i+k}=x_{j+k}$ для всех $k\ge0$ — последовательность становится периодической навсегда. Это и есть цикл. Структура получается **ρ-образной**: хвост (пройденный один раз) + цикл (бесконечно повторяющийся).

**Почему именно узел-дубликат — это точка входа в цикл:**
- Значения $\ge 1$ ⟹ ни один узел не указывает на индекс `0` ⟹ у узла `0` in-degree = 0, и он не может быть частью цикла (в цикл всегда входит стрелка изнутри цикла).
- Значит, стартуя с `0`, мы обязательно проходим **реальный** хвост длины $\ge 1$ перед входом в цикл.
- Точка слияния хвоста и цикла всегда получает **два разных входящих ребра**: одно — из хвоста, одно — изнутри цикла ⟹ in-degree этой точки $\ge 2$.
- По условию задачи только **одно** число (дубликат $d$) встречается дважды, значит только у **одного** узла во всём графе in-degree = 2, у всех остальных — 1 (или 0 для узла `0`).
- Значит точка слияния = $d$, других кандидатов физически нет.

**Про "другие" циклы:**
Теоретически среди узлов $1,\dots,n$ могут существовать и другие, полностью изолированные циклы, не связанные со стартом `0` (например, если в массиве где-то отдельно есть пара $a[i]=j,\ a[j]=i$, не пересекающаяся с путём из `0`). Это не мешает алгоритму: раз стартуем из `0` и идём по стрелкам, такие посторонние компоненты никогда не посещаются. Единственный цикл, который нас волнует — тот, что достижим из `0`, а его точка входа гарантированно — дубликат (по аргументу выше).

## 4. Почему работает встреча "зайца" и "черепахи"

**Обозначения:** $\mu$ — длина хвоста (шагов от `0` до входа в цикл $d$), $\lambda$ — длина цикла, $m$ — момент первой встречи.

**Почему они вообще встретятся, причём именно в цикле:**
Заяц (скорость 2) обгоняет черепаху (скорость 1) и первым входит в цикл. Как только оба находятся внутри цикла, расстояние между ними (по кругу) сокращается на 1 узел за шаг — рано или поздно оно станет равным 0, то есть они встретятся. Встреча физически не может произойти в хвосте, так как в хвост нельзя вернуться.

**Почему $m$ кратно $\lambda$:**
Позиции относительно $d$: черепаха — $(m-\mu) \bmod \lambda$, заяц — $(2m-\mu)\bmod\lambda$. Равенство позиций даёт $m \equiv 2m \pmod \lambda \Rightarrow m \equiv 0 \pmod\lambda$.

**Почему расстояние от точки встречи $M$ до $d$ равно $\mu$ (по модулю $\lambda$):**
Позиция $M$ относительно $d$ равна $(m-\mu)\bmod\lambda$. Так как $m$ кратно $\lambda$, это $= (-\mu)\bmod\lambda$ — то есть **пройдя от $M$ вперёд ровно $\mu$ шагов (с учётом кругов), попадаем точно в $d$.**

**Финал:**
- От старта `0` до $d$ — ровно $\mu$ шагов (по определению).
- От точки встречи $M$ до $d$ — тоже ровно $\mu$ шагов (доказано выше).

Запускаем два указателя с одинаковой скоростью (по 1 шагу): один из `0`, другой из $M$. Обоим требуется одинаковое число шагов ($\mu$), значит они **обязательно окажутся в $d$ одновременно** — и это и есть искомый дубликат.
