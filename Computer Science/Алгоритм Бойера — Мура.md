**Алгоритм Бойера — Мура** — алгоритм поиска подстроки в строке. Его главная особенность заключается в том, что сравнение символов начинается **с конца искомого шаблона**, а при несовпадении алгоритм может пропустить сразу несколько символов текста.

```text
Текст:    THIS IS A SIMPLE EXAMPLE
Шаблон:             EXAMPLE
```

В отличие от обычного поиска, алгоритм не проверяет каждую позицию текста последовательно.

---

## Основная идея

Пусть необходимо найти шаблон `pattern` в строке `text`.

Алгоритм:

1. Совмещает шаблон с началом текста.
    
2. Сравнивает символы шаблона и текста **справа налево**.
    
3. Если символы совпадают — переходит к следующей паре слева.
    
4. Если найдено несовпадение — сдвигает шаблон вправо.
    
5. Размер сдвига определяется специальными правилами.
    

```python
t = "данные"

# Этап 1: формирование таблицы смещений

S = set()  # уникальные символы в шаблон
M = len(t) # число символов в шаблон
d = {}     # словарь смещений

for i in range(M-2, -1, -1): # итерации с предпоследнего символа
    if t[i] not in S:        # если символ еще не добавлен в таблицу
        d[t[i]] = M-i-1
        S.add(t[i])

if t[M-1] not in S:     # отдельно формируем последний символ
	d[t[M-1]] = M       # если он уникален в шаблоне, то делаем смещение на длину шаблона

d['*'] = M              # смещения для прочих символов

print(d)

# Этап 2: поиск образа в строке

a = "ососбенные данный метеоданные"
N = len(a)

if N >= M:
    i = M-1       # счетчик проверяемого символа в строке

    while(i < N):
        k = 0
        j = 0
        flBreak = False
        for j in range(M-1, -1, -1):
            if a[i-k] != t[j]:
                if j == M-1:
                    off = d[a[i]] if d.get(a[i], False) else d['*']  
                    # смещение, если не равен последний символ образа
                else:
                    off = d[t[j]]   # смещение, если не равен не последний символ образа

                i += off    # смещение счетчика строки
                flBreak = True  # если несовпадение символа, то flBreak = True
                break

            k += 1          # смещение для сравниваемого символа в строке

        if not flBreak:          
        # если дошли до начала образа, значит, все его символы совпали
            print(f"образ найден по индексу {i-k+1}")
            break
    else:
        print("образ не найден")
else:
    print("образ не найден")
```


## Сложность

Пусть:

- `n` — длина текста
- `m` — длина шаблона
- `k` — количество различных символов в шаблоне

| Случай                            |       Сложность |
| --------------------------------- | --------------: |
| Предварительная обработка шаблона |          `O(m)` |
| Лучший случай                     |      `O(n / m)` |
| Средний случай                    | близко к `O(n)` |
| Худший случай упрощённой версии   |      `O(n × m)` |
| Дополнительная память             |          `O(k)` |

На практике алгоритм особенно эффективен, когда:

- текст большой;
    
- шаблон достаточно длинный;
    
- алфавит содержит много различных символов.
