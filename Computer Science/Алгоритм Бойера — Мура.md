**Алгоритм Бойера — Мура** — алгоритм поиска подстроки в строке. Его главная особенность заключается в том, что сравнение символов начинается **с конца искомого шаблона**, а при несовпадении алгоритм может пропустить сразу несколько символов текста.

```text
Текст:    THIS IS A SIMPLE EXAMPLE
Шаблон:             EXAMPLE
```

В отличие от обычного поиска, алгоритм не проверяет каждую позицию текста последовательно.

---

## Основная идея

Пусть необходимо найти шаблон `pattern` в строке `text`.

Алгоритм:

1. Совмещает шаблон с началом текста.
    
2. Сравнивает символы шаблона и текста **справа налево**.
    
3. Если символы совпадают — переходит к следующей паре слева.
    
4. Если найдено несовпадение — сдвигает шаблон вправо.
    
5. Размер сдвига определяется специальными правилами.
    

Для вычисления сдвига используются две эвристики:

- правило плохого символа;
    
- правило хорошего суффикса.
    

---

## Правило плохого символа

Если символ текста не совпал с символом шаблона, алгоритм ищет последнее вхождение этого символа в шаблоне.

Например:

```text
Текст:    ABCDABC
Шаблон:   ABCE
             ↑
```

Символ `D` отсутствует в шаблоне `ABCE`, поэтому шаблон можно полностью сдвинуть за символ `D`.

Для шаблона заранее создаётся таблица последних позиций символов:

```python
pattern = "ABCA"

last_occurrence = {
    "A": 3,
    "B": 1,
    "C": 2
}
```

Если несовпадение произошло на позиции `j`, сдвиг вычисляется так:

```text
shift = j - last_occurrence[bad_character]
```

Если символ отсутствует в шаблоне, считается, что его позиция равна `-1`.

Чтобы сдвиг всегда был положительным:

```text
shift = max(1, j - last_occurrence[bad_character])
```

---

## Правило хорошего суффикса

**Хороший суффикс** — часть шаблона, которая уже совпала с текстом перед обнаружением несовпадения.

```text
Текст:    ...XYAB
Шаблон:      ZZAB
               ↑
```

Суффикс `AB` уже совпал. Алгоритм пытается найти другое вхождение `AB` внутри шаблона и совместить его с найденной частью текста.

Если такого вхождения нет, алгоритм ищет наиболее длинный суффикс, который одновременно является префиксом шаблона.

Это правило позволяет делать более крупные сдвиги, но его реализация сложнее правила плохого символа.

## Упрощённая реализация на Python

Ниже используется только правило плохого символа. Такой вариант часто называют алгоритмом **Бойера — Мура — Хорспула** или упрощённым вариантом Бойера — Мура.

```python
def boyer_moore_search(text: str, pattern: str) -> int:
    if pattern == "":
        return 0

    if len(pattern) > len(text):
        return -1

    # Последняя позиция каждого символа в шаблоне
    last_occurrence = {
        char: index
        for index, char in enumerate(pattern)
    }

    text_length = len(text)
    pattern_length = len(pattern)

    shift = 0

    while shift <= text_length - pattern_length:
        # Начинаем сравнение с конца шаблона
        j = pattern_length - 1

        while j >= 0 and pattern[j] == text[shift + j]:
            j -= 1

        # Все символы шаблона совпали
        if j < 0:
            return shift

        bad_character = text[shift + j]
        last_position = last_occurrence.get(bad_character, -1)

        shift += max(1, j - last_position)

    return -1
```

Пример использования:

```python
text = "THIS IS A SIMPLE EXAMPLE"
pattern = "EXAMPLE"

position = boyer_moore_search(text, pattern)

print(position)
```

Результат:

```text
17
```

Если подстрока не найдена, функция возвращает `-1`.

## Поиск всех вхождений

```python
def boyer_moore_search_all(text: str, pattern: str) -> list[int]:
    if pattern == "":
        return list(range(len(text) + 1))

    if len(pattern) > len(text):
        return []

    last_occurrence = {
        char: index
        for index, char in enumerate(pattern)
    }

    positions = []
    shift = 0

    while shift <= len(text) - len(pattern):
        j = len(pattern) - 1

        while j >= 0 and pattern[j] == text[shift + j]:
            j -= 1

        if j < 0:
            positions.append(shift)
            shift += 1
        else:
            bad_character = text[shift + j]
            last_position = last_occurrence.get(bad_character, -1)

            shift += max(1, j - last_position)

    return positions
```

Пример:

```python
text = "ABAAABAA"
pattern = "ABA"

print(boyer_moore_search_all(text, pattern))
```

Результат:

```text
[0, 4]
```

## Сложность

Пусть:

- `n` — длина текста;
    
- `m` — длина шаблона.
    

|Случай|Сложность|
|---|--:|
|Предварительная обработка шаблона|`O(m)`|
|Лучший случай|`O(n / m)`|
|Средний случай|близко к `O(n)`|
|Худший случай упрощённой версии|`O(n × m)`|
|Дополнительная память|`O(k)`|

`k` — количество различных символов в шаблоне.

На практике алгоритм особенно эффективен, когда:

- текст большой;
    
- шаблон достаточно длинный;
    
- алфавит содержит много различных символов.
    

---

## Преимущества

- Может пропускать большие участки текста.
    
- Обычно быстрее наивного поиска.
    
- Хорошо работает с длинными шаблонами.
    
- Не требует проверки каждой позиции текста.
    

## Недостатки

- Полная реализация достаточно сложна.
    
- Для коротких шаблонов выигрыш может быть небольшим.
    
- В худшем случае сложность может достигать `O(n × m)`.
    
- Требуется предварительная обработка шаблона.
    

---

## Сравнение с наивным поиском

### Наивный алгоритм

```text
Сравнивает шаблон с каждой возможной позицией текста.
```

После несовпадения сдвигает шаблон только на один символ.

### Алгоритм Бойера — Мура

```text
Сравнивает символы справа налево.
```

После несовпадения может сдвинуть шаблон сразу на несколько позиций.

---

## Кратко

> Алгоритм Бойера — Мура ищет подстроку, сравнивая шаблон с текстом справа налево. При несовпадении он использует информацию о символах и совпавших суффиксах, чтобы сдвинуть шаблон сразу на несколько позиций.
