# Что такое эмбеддинги? Объяснение векторных представлений

> Видео: https://www.youtube.com/watch?v=AoclBY_SwC8

> Формат: смысловой учебный конспект, а не дословная стенограмма.
## Главная идея

Чтобы нейросеть могла работать с текстом, дискретные объекты нужно представить числами.

**Embedding** — обучаемый плотный вектор объекта.

Например:

\[
\text{cat}\rightarrow[0.21,-0.44,0.73,\dots]
\]

\[
\text{dog}\rightarrow[0.18,-0.39,0.69,\dots]
\]

Если обучение прошло хорошо, семантически близкие объекты оказываются близкими и геометрически.

## Почему ID слова недостаточно

Если:

```text
apple = 1
pear = 2
tractor = 3
```

из числового расстояния между ID нельзя делать семантические выводы.

ID — это просто адрес объекта в словаре.

## One-hot encoding

Для словаря из \(V\) слов:

```text
cat = [0,0,1,0,...]
dog = [0,0,0,1,...]
```

Проблемы:

- размерность равна \(V\);
- почти все координаты нули;
- разные слова ортогональны;
- близость `cat/dog` ничем не отличается от `cat/tractor`.

## Embedding matrix

Пусть:

- размер словаря — \(V\);
- размер embedding — \(d\).

Тогда:

\[
E\in\mathbb R^{V\times d}
\]

Каждая строка \(E_i\) — vector соответствующего token.

```text
token id
   ↓
выбор строки E
   ↓
embedding vector
```

Обычно:

\[
d\ll V
\]

Например:

```text
V = 50 000
d = 768
```

## Как появляется смысл

Изначально vectors могут быть случайными.

При обучении gradient descent меняет их так, чтобы модель лучше решала задачу.

Семантика появляется как полезная геометрическая структура пространства.

Слова с похожими контекстами получают похожие representations.

## Cosine similarity

Одна из стандартных мер близости:

\[
\boxed{
\cos(a,b)
=
\frac{a\cdot b}{\|a\|\|b\|}
}
\]

Интуитивно:

```text
≈ 1  → направления похожи
≈ 0  → почти ортогональны
≈ -1 → противоположны
```

## Статические и контекстные представления

### Статический embedding

Один token всегда получает один исходный vector.

### Contextual representation

После прохождения Transformer представление зависит от соседних токенов.

Например слово `bank`:

```text
river bank
bank account
```

в начале может иметь один token embedding, но после self-attention его hidden state станет разным.

## Вектор предложения

Предложение состоит из многих токенов.

Чтобы получить один vector всего текста, используют:

- `[CLS]`;
- mean pooling;
- weighted pooling;
- отдельную embedding model, специально обученную кодировать целые тексты.

Поэтому sentence embedding model — это уже полноценная нейросеть, а не просто таблица word vectors.

## Связь с Transformer

```text
текст
 ↓ tokenizer
token IDs
 ↓ embedding matrix
token vectors
 ↓ + positional information
Transformer
 ↓
contextual vectors
```

Контекст появляется благодаря attention.

→ [[13 - Механизм внимания в LLM. Self-Attention]]

## Что запомнить

- token ID — адрес, не смысл;
- one-hot не кодирует семантическую близость;
- embedding — плотный обучаемый vector;
- embedding matrix имеет размер \(V\times d\);
- contextual representation отличается от исходного embedding.
