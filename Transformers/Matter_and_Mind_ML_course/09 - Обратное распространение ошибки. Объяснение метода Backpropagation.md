# Обратное распространение ошибки. Объяснение метода Backpropagation

> Видео: https://www.youtube.com/watch?v=R28E0AEy6hc

> Формат: смысловой учебный конспект, а не дословная стенограмма.
## Главная идея

Gradient descent требует:

\[
\frac{\partial L}{\partial\theta_i}
\]

для всех параметров.

Backpropagation эффективно вычисляет эти производные с помощью цепного правила.

Важно:

> backpropagation вычисляет gradients, но сам веса не обновляет.

Обновление выполняет optimizer.

## Вычислительный граф

Сложная функция разбивается на элементарные операции.

Например:

\[
L=(wx+b-y)^2
\]

можно представить графом:

```text
w ─┐
   × → a ─┐
x ─┘      + → z ─┐
b ────────┘      - → e → square → L
y ───────────────┘
```

## Forward pass

Сначала считаются значения слева направо:

```text
input → prediction → loss
```

Промежуточные значения сохраняются.

## Backward pass

Затем производные идут справа налево:

```text
loss → local derivatives → parameter gradients
```

Начало:

\[
\frac{\partial L}{\partial L}=1
\]

## Chain rule

Если:

\[
y=f(u),\qquad u=g(x)
\]

то:

\[
\boxed{
\frac{dy}{dx}
=
\frac{dy}{du}
\frac{du}{dx}
}
\]

Для длинной цепочки локальные производные перемножаются.

## Пример

Пусть:

\[
a=wx
\]

\[
z=a+b
\]

\[
L=z^2
\]

Тогда:

\[
\frac{\partial L}{\partial z}=2z
\]

\[
\frac{\partial z}{\partial a}=1
\]

\[
\frac{\partial a}{\partial w}=x
\]

Следовательно:

\[
\boxed{
\frac{\partial L}{\partial w}=2zx
}
\]

## Почему это эффективно

Общие участки графа не пересчитываются отдельно для каждого параметра.

Backprop переиспользует уже найденные промежуточные derivatives.

По сути это динамическое программирование на computational graph.

## Если путь не один

Если переменная влияет на loss по нескольким веткам, gradients складываются:

\[
\frac{\partial L}{\partial x}
=
\sum_k
\left(
\frac{\partial L}{\partial x}
\right)_k
\]

## В нейросети

Для:

\[
z=Wx+b
\]

\[
a=f(z)
\]

из upstream gradient:

\[
\frac{\partial L}{\partial a}
\]

получаем:

\[
\frac{\partial L}{\partial z}
=
\frac{\partial L}{\partial a}
\odot f'(z)
\]

а затем gradients по:

- \(W\);
- \(b\);
- входу \(x\).

Gradient по \(x\) передаётся предыдущему слою.

## Backprop vs optimizer

### Backprop

```text
Loss
↓
∇θL
```

### Optimizer

```text
∇θL
↓
θ ← θ - η∇θL
```

Не путать эти два процесса.

## Что запомнить

1. Forward считает значения.
2. Backward считает derivatives.
3. Основа — chain rule.
4. Общие промежуточные вычисления переиспользуются.
5. Backprop делает обучение глубоких сетей вычислительно реальным.
