Условие

Дан неотсортированный массив целых чисел nums. Нужно вернуть наименьшее положительное целое число, которого в нём нет.

Ограничение: время O(n) и дополнительная память O(1).

Идея: флаги хранятся в знаках

Ячейка с индексом k отвечает за число k + 1. Если оно встретилось, делаем значение в этой ячейке отрицательным.

Модуль значения не теряется: прочитать исходное число можно через abs(...). Поэтому смена знака ничего не портит.

В конце ищем первую ячейку без пометки. Если это ячейка k, ответ k + 1.

У приёма есть две проблемы: в массиве уже могут быть отрицательные числа, а ноль нельзя «сделать отрицательным». Алгоритм решает обе.

Алгоритм: три прохода

  1. Обнуляем отрицательные числа

    Они нам не нужны, а минус должен остаться свободным для пометок. Заменяем каждое nums[i] < 0 на 0.

  2. Расставляем пометки

    Для каждого i берём value = abs(nums[i]). Если 1 ≤ value ≤ n, смотрим в ячейку nums[value − 1]:

Что лежит в ячейкеЧто делаемЗачем

  1. Ищем первую ячейку без пометки

    Идём по i от 1 до n. Если nums[i − 1] ≥ 0, числа i в массиве нет — это ответ.

  2. Если все ячейки отмечены

    В массиве есть все числа от 1 до n, ответ n + 1.

class Solution:
    def firstMissingPositive(self, nums: list[int]) -> int:

        length = len(nums)

        # 1. убираем отрицательные: знак «минус» теперь свободен для пометок
        for i in range(length):
            if nums[i] < 0:
                nums[i] = 0

        # 2. ставим пометки: ячейка value - 1 отвечает за число value
        for i in range(length):

            value = abs(nums[i])

            if 1 <= value <= length:
                if nums[value - 1] == 0:
                    nums[value - 1] = -1 * (length + 1)
                elif nums[value - 1] > 0:
                    nums[value - 1] *= -1

        # 3. первая ячейка без минуса — ответ
        for i in range(1, length + 1):
            if nums[i - 1] >= 0:
                return i

        return length + 1
function firstMissingPositive(nums) {
  const length = nums.length;

  // 1. убираем отрицательные
  for (let i = 0; i < length; i++) {
    if (nums[i] < 0) nums[i] = 0;
  }

  // 2. ставим пометки
  for (let i = 0; i < length; i++) {
    const value = Math.abs(nums[i]);

    if (value >= 1 && value <= length) {
      if (nums[value - 1] === 0) {
        nums[value - 1] = -(length + 1);
      } else if (nums[value - 1] > 0) {
        nums[value - 1] *= -1;
      }
    }
  }

  // 3. первая ячейка без минуса — ответ
  for (let i = 1; i <= length; i++) {
    if (nums[i - 1] >= 0) return i;
  }

  return length + 1;
}

Почему именно так

Зачем обнулять отрицательные

Если оставить их как есть, исходный минус нельзя будет отличить от нашей пометки. Ответ получится неверным.

Зачем писать −(n + 1) вместо 0

Ноль нельзя сделать «отрицательным». Значение −(n + 1) по модулю больше n, поэтому позже оно не будет принято за настоящее число и ничего не пометит.

Зачем брать abs

К моменту чтения ячейка уже может быть помечена. Модуль возвращает исходное число, и его нужно обработать, как и остальные.

Почему в конце проверка ≥ 0

Ячейка без пометки хранит либо положительное число, либо ноль. Оба варианта значат, что соответствующего числа в массиве не было.

Сложность

Время: O(n)

Три независимых прохода по массиву, каждый делает константную работу на элемент.

Память: O(1)

Новых структур нет. Пометки хранятся в знаках элементов самого массива, плюс несколько переменных.

Цена решения: входной массив изменяется. Если его нужно сохранить, придётся сделать копию, и тогда память станет O(n).

Итог

  1. Ответ лежит в диапазоне 1…n + 1

    Остальные числа можно игнорировать.

  2. Знак числа — это флаг

    Ячейка k отвечает за число k + 1: минус означает «встречалось».

  3. Сначала зачищаем массив

    Отрицательные числа превращаем в нули, а пометку для нуля пишем как −(n + 1).

  4. Первая ячейка с nums[i − 1] ≥ 0 даёт ответ i

    Если таких нет — ответ n + 1. Итого O(n) по времени и O(1) по памяти.
